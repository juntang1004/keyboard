도록키보드 수정판 (원작자 v5.5.0 기반)

■ 설치
 - 원본 도록키보드랑 서명이 달라서, 원본 앱을 먼저 지우고 설치해야 함
 - 설치 후: 앱 열기 → 키보드 전환 → 도록 키보드 선택
 - 구글 드라이브에서 받을 때 "바이러스 검사를 할 수 없음" 경고가 떠도 다운로드 누르면 됨

■ 바뀐 점
 - 빠르게 쳐도 글자 씹힘 수정 (손가락마다 따로 처리)
 - 천지인 · 나랏글 추가 (삼성 키보드 배열 그대로), 쿼티도 삼성 배열로
 - 나랏글: 획추가 · 쌍자음 · 쉼표 길게 누르면 기호, 삼성 나랏글과 같은 입력 결과 55가지 확인
 - 123 숫자판 / 특수문자 1~3 / 영어 쿼티 전부 삼성 배열
 - 천지인 · 나랏글 위 숫자 바 (켜고 끄기 가능)
 - 툴바: 편집(방향키·선택·복사·붙여넣기), 클립보드, 문구(자주 쓰는 글), 커서 이동
 - 설정 앱 새 디자인 (스위치 소리 축별 정리, 툴바·숫자 바 설정)
 - 키 글꼴은 폰에 깔린 삼성 키보드의 글꼴을 빌려 씀 (삼성 키보드 없으면 기본 글꼴)

■ 오타 제안 · 자동 교정 추가판
 - 설정 › 오타 제안 · 자동 교정 (쿼티 한글)
 - 1단계: 스페이스와 윗줄 키(ㅌㅊㅍㅠㅜㅡ)가 뒤바뀐 오타. 예) 바부먹자 → 밥 먹자 (밥 + ㅜ 가 "바부"로 합쳐짐)
   터치 위치(따라 쓰기로 배운 치우침 포함)와 음절 연결 통계(assets/typo_lm.bin: 위키백과 + 자막 어절 빈도)로 판단
 - 오타 제안(기본 켜짐): 툴바에 고칠 말을 띄우고, 누르면 바꿈
 - ㅠ·ㅜ 오타 자동 교정(기본 켜짐): 스페이스와 ㅠ·ㅜ가 뒤바뀐 오타는 확실하면(점수차 3 이상) 띄어쓰기·마침표·엔터에서 바로 고침
 - 그 밖의 오타도 자동 교정(기본 꺼짐): 아주 확실할 때만 띄어쓰기·마침표·엔터를 누르는 순간 바꿈. 바로 지우기 = 되돌리기
   (되돌린 말은 "고치지 않기로 한 말"에 기억해서 다시 안 고침)
 - 자동 학습(기본 켜짐): 자주 친 단어(3번 이상)를 기억, 제안으로 고친 터치는 터치 보정 기록에 추가
 - 내 단어: 직접 등록 / 자동 학습 목록, 검색, 삭제
 - 고정 바꾸기: 오타 → 바꿀 말 (예: ㄱㅅ → 감사합니다), 검색, 삭제. 제안을 꺼도 동작
 - 비밀번호·이메일·주소 입력칸에서는 제안·학습 안 함. ㅠㅠ ㅜㅜ처럼 겹쳐 친 것은 건드리지 않음
 - 소스: src/Typo.java, SettingsUi.java 끝부분, Ext.java typo* 함수 / 통계 만들기: mod2/lm_build.py / 테스트: test/TypoTest.java

■ 터치 범위 직접 그리기
 - 설정 › 오타 학습 › 터치 범위 상세 설정에서 키를 고르면 그 키의 범위만 색칠 + 그 키의 터치 점
   (초록: 제대로 누름, 빨강: 오타, 파랑 빈 동그라미: 다른 키를 누르려다 이 키로 눌림)
 - "직접 그리기": 그리기 / 지우개 / 되돌리기 / 완료, 붓 크기 3단계. 칠한 곳만 바뀌고 다른 곳은 그대로
   그리기 = 이 키 범위 넓히기, 지우개 = 이 키 범위에서 빼기(가장 가까운 다른 키가 가져감)
   다른 키의 가운데 30%는 칠해지지 않음 (그 키를 못 누르게 되는 것 방지)
 - 터치 점은 늘 반투명: 많이 겹친 곳일수록 진하게 보임 (편집 중에는 더 흐리게), "점 숨기기"로 끄기 가능
 - 확대(최대 5배)·축소·상하좌우 이동·전체 버튼. 붓은 화면에서 같은 크기라 확대하면 더 섬세하게 칠해짐
 - 직접 그린 범위가 이동·크기 보정보다 먼저 적용, 추천 범위를 적용해도 남음. 키 기본값으로 / 모든 키 기본값으로 = 그린 범위도 지움
 - 학습 결과에서 키를 누르면 그 키의 인식 범위도 함께 색칠. "모든 키 보기"로 기록된 모든 키 결과
 - 추천 범위 적용 두 가지: 모든 키 / 고른 키만 (학습 결과·상세 설정 둘 다)
 - 키보드 높이를 바꿔도 범위·그린 범위·기록은 키 크기 비율로 저장돼 그대로 맞음. 설정 그림의 키 비율도 키보드를 열 때 갱신
 - 기록 출처 구분: 따라 쓰기 / 평소 타자 / 오타 교정 / 예전 기록(구분 전). 예전 기록만 지우기 가능
 - 평소 타자: 글자·스페이스·마침표는 4번에 1번(스페이스 3번에 1번) 기록. 친 뒤 6타 안에 지우거나 오타 교정이 일어나면 버림
 - 추천 계산: 키마다 최근 300개, 150개 지날 때마다 무게 절반. 오타 교정 기록은 평소 기록과 같은 비율로만 반영
 - 추천 비교: 지금 설정 / 추천 + 그린 범위 유지 / 그린 범위 지우고 추천만 → 오타 수. "그린 범위 지우고 모든 키에 추천 범위 적용" 버튼
 - 테스트: test/NormalTest.java
 - 테스트: test/PaintTest.java

■ 맞춤법 제안 추가판 (dorok-keyboard-v5.5.0-mod-spell.apk)
 - 설정 › 오타 제안 · 자동 교정 › 맞춤법: "맞춤법 제안" 스위치 (기본 켜짐)
